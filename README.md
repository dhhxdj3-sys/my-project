# 个人技术博客

## 项目介绍

基于 Vue3 开发的个人博客，
用于记录前端学习过程和展示练习项目。


## 技术栈

- Vue3
- JavaScript
- Vite
- Vue Router


## 功能

- 个人主页展示
- 技能展示
- 博客文章系统
- 点赞 / 收藏 / 评论功能
- 项目展示


## 实践项目

### 猜数字小游戏
- Vue3 + JavaScript
- 输入判断、次数统计


### 学生成绩管理系统
- Vue3 + Computed
- 数据展示、成绩计算


### 购物车系统
- Vue3 + Ref + Computed
- 商品添加、数量修改、价格计算
